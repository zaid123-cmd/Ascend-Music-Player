# 🎵 Ascend Music Player

**Ascend** is a sleek, Spotify-inspired music player designed for clean UI, smooth user interaction, and a highly responsive listening experience. Built as a personal passion project focused on modern front-end practices and interactive audio playback.

---

## ✨ Features

- Beautiful and responsive UI inspired by modern music streaming platforms
- Play, pause, next/previous track functionality
- Seek bar with live progress tracking
- Custom hover effects on controls and album art
- Fully mobile responsive design

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript 
- Spline 3d embedding

## 🎛️ Customization

- **Animations**: Use GSAP, Spline, or Lottie to add transitions or music visualizers.
